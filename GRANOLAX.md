# Granolax

Granolax est l'enregistreur de rendez-vous d'Antoine Marquis. C'est une copie adaptée de
[Meetily Community Edition](https://github.com/Zackriya-Solutions/meetily) (licence MIT,
Copyright (c) 2024 Zackriya Solutions ; voir LICENSE.md, conservé tel quel).

Changements par rapport à Meetily :
- nom de l'application, fenêtre et installateur : Granolax (identifiant com.granolax.app) ;
- transcription en français par défaut ;
- enregistrements et transcriptions rangés dans Documents\Granolax (un sous-dossier par rendez-vous,
  avec transcripts.json et metadata.json), pour remplir la page Granolax ;
- pas de vérification automatique des mises à jour de Meetily, statistiques d'usage désactivées ;
- installateur Windows fabriqué par la GitHub Action « Granolax - installateur Windows »
  à chaque envoi sur la branche granolax, publié dans les Releases.
